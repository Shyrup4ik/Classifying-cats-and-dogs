# Классификация кошек и собак с ResNet18

Учебный проект на PyTorch: подготовка фотографий, обучение ResNet18, оценка качества и вывод вероятностей кошки и собаки для нового изображения.

## Файлы проекта

- `ResNet18_cat_or_dog.ipynb` — ноутбук с кодом, пояснениями и результатами исходного запуска.
- `requirements.txt` — основные библиотеки проекта.
- `.gitignore` — исключает фотографии, веса, подготовленные датасеты и временные файлы.

Фотографии и обученные веса в папку репозитория не включены. Источник и условия распространения датасета в предоставленном ноутбуке не указаны.

## Данные

Исходная папка: `~/Downloads/train`. Названия файлов: `cat.1.jpg`, `dog.1.jpg` и аналогичные.

Изображения преобразуются в RGB-тензоры размером `3×32×32`. Метки: `cat = 0`, `dog = 1`. Батч имеет форму `(batch_size, 3, 32, 32)`.

В записанном запуске использованы 9972 фотографии: 6981 для train, 997 для validation и 1994 для test. Параметр `N_IMAGES = 10000` задаёт верхнюю границу; для ровно 10 000 изображений исходному набору не хватает 28 файлов.

Каждый запуск подготовки создаёт новую папку `dataset_resnet_*`. Исходные фотографии не перемещаются и не удаляются.

## Модель

Используется предобученная ResNet18. Для небольших изображений шаг первой свёртки изменён на `(1, 1)`, а начальный `maxpool` заменён на `nn.Identity()`. Последний слой выдаёт два числа.

Настройки записанного запуска:

| Параметр | Значение |
|---|---|
| Размер изображения | 32×32 |
| Batch size | 32 |
| Оптимизатор | Adam |
| Learning rate | 0.0001 |
| Weight decay | 0.0001 |
| Функция ошибки | CrossEntropyLoss |
| Seed | 42 |
| Фактически выполнено эпох | 6 |
| Устройство | MPS |

В настройках также есть `EPOCHS = 5`, но текущий вызов `train(...)` содержит число `6` напрямую. Поэтому изменение `EPOCHS` пока не меняет длительность обучения.

## Важные особенности текущего кода

В этой версии отредактированы пояснения; код и сохранённые результаты оставлены как в исходном файле.

1. `RandomHorizontalFlip` находится в общем `transform`. Поэтому случайное отражение применяется к train, validation, test и новым фотографиям. Проверочные метрики и ответы на одно фото могут меняться при повторении. Для постоянной оценки нужно отдельно задать обработку train и обработку без случайностей для остальных данных, затем повторно измерить метрики.
2. В обучающей модели изменены `conv1.stride` и `maxpool`, но в шаге 12 эти настройки не повторены. Веса могут загрузиться без ошибки, однако расчёт предсказаний будет отличаться. Перед использованием новых фото нужно добавить после создания `saved_model` строки ниже. Повторное обучение только из-за этого исправления не требуется.

```python
saved_model.conv1.stride = (1, 1)
saved_model.maxpool = nn.Identity()
```

Метрики шага 11 считаются на обучающей архитектуре с загруженными лучшими весами. Они не подтверждают качество отличающейся архитектуры из шага 12.

## Запуск на Mac

1. Открой Терминал и перейди в папку проекта:

```bash
cd /путь/к/cat-dog-resnet18
```

2. Создай окружение и установи библиотеки:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install notebook
python -m notebook
```

3. Открой `ResNet18_cat_or_dog.ipynb` и используй созданное окружение Python.
4. Проверь `SRC_DIR`: он должен указывать на твои фотографии.
5. Выполняй ячейки сверху вниз. Для скачивания предобученных весов нужен интернет.

Первая ячейка исходного кода также выполняет установку/обновление torch и torchvision. Для повторяемой среды эти две команды можно пропустить после установки зависимостей.

В `requirements.txt` указаны названия библиотек без выдуманных версий: подтверждённый список версий исходного окружения не предоставлен. Последняя заполненная ячейка ноутбука умеет записать установленные версии пяти библиотек. После успешного запуска сохрани полученный файл для повторения окружения.

## Сохранение и новое фото

Веса лучшей эпохи сохраняются в `cat_dog_fixed.pt` в рабочей папке. При следующем обучении файл может обновиться, поэтому удачный результат можно заранее скопировать под другим именем.

Для предсказания без повторного обучения нужны шаги 1, 2, 12, 13 и 15. Перед этим учти два исправления из раздела выше: одинаковую архитектуру при загрузке и отсутствие случайного отражения при предсказании.

В шаге 15 укажи путь:

```python
photo_path = "~/Downloads/photo.jpeg"
```

Программа покажет фотографию, оба процента и класс с большей вероятностью. Название файла не влияет на классификацию. Вероятности — оценки сети, а не гарантия правильного ответа. Модель выбирает между двумя классами даже для другого объекта.

## CSV и веса — разные файлы

`cat_dog_fixed.csv` содержит фотографии в числовом виде: метка и 3072 значения RGB-пикселей в каждой строке. Порядок пикселей: строка за строкой, каналы R, G, B. Значения от 0 до 255, без нормализации и случайного отражения.

`cat_dog_fixed.pt` содержит веса сети. CSV не заменяет этот файл и не позволяет восстановить обучение самостоятельно.

## Загрузка на GitHub

Создай пустой репозиторий на GitHub. Из папки проекта выполни:

```bash
git init
git branch -M main
git add README.md requirements.txt .gitignore ResNet18_cat_or_dog.ipynb
git diff --cached --stat
git commit -m "Add ResNet18 cat and dog classification project"
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

Замени `USERNAME` и `REPOSITORY` на свои значения. Репозиторий не содержит весов и датасета; человеку, который его скачает, понадобятся свои данные для обучения или твой совместимый файл весов.
